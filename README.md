# Patient 360 Healthcare Copilot

**Unified EHR, Claims & Clinical Document Intelligence with Cited Evidence**

Built entirely on Snowflake Cortex AI — no external infrastructure.

---

## What Is This?

Patient 360 Healthcare Copilot is a healthcare intelligence application that unifies five siloed data sources into a single interactive experience for doctors and care managers. Instead of switching between EHR systems, claims databases, clinical document repositories, and drug safety portals, clinicians can explore patient data visually and ask natural language questions — getting cited, evidence-based answers every time.

**Live App:** Deployed as a Streamlit-in-Snowflake web application.
**GitHub:** [github.com/Pratush12/snowflake-patient-360](https://github.com/Pratush12/snowflake-patient-360)

---

## The Problem

Care and life sciences teams work across siloed systems:

- **EHR Records** — Patient demographics, encounters, diagnoses, medications, and lab results scattered across structured databases
- **Insurance Claims** — Billing data with amounts, CPT codes, and denial statuses in separate systems
- **Clinical Documents** — Physician notes, discharge summaries, and radiology reports buried as unstructured text
- **Regulatory Documents** — FDA safety alerts, clinical guidelines, and formulary policies exist as standalone files nobody searches
- **Drug Safety Data (CTGOV)** — Adverse effects from clinical trials are never linked back to patient medication lists

When a doctor asks *"What should I worry about for this patient?"* — no single system can answer by combining structured records, clinical notes, regulatory alerts, AND clinical trial safety data.

## Features

### 1. Animated Home Page
Landing page with feature cards, live data statistics (50 patients, 3,238 records, 228 documents, 40 CTGOV adverse events), technology stack badges, and navigation to all app sections.

### 2. Patient List with Risk Stratification
- Risk tier summary cards: **Critical**, **High**, **Moderate**, **Low** with patient counts
- Searchable and filterable patient table
- HCC scores, readmission risk percentages, fall risk, medication adherence
- One-click drill-through to Patient 360 or Copilot Chat

### 3. Patient 360 Dashboard
- **AI-Generated Clinical Summary** — A concise paragraph generated by Cortex LLM (llama3.1-8b) covering the patient's conditions, medications, risk level, and next-visit priorities. Designed for a new doctor taking over care.
- **Patient Journey Timeline** — Chronological encounter history with type indicators (Emergency, Inpatient, Office Visit, Telehealth) and an encounters-over-time chart
- **Visual Dashboard** — Charts for encounter types, diagnosis categories, medication classes, and claims by status
- **Lab Results Trend** — Select any lab test to see values plotted over time
- **CTGOV Medication Safety** — Automatic cross-reference of active medications against trial-reported adverse events, with serious event warnings
- **Detailed Records** — Tabbed raw data for encounters, diagnoses, medications, labs, and claims

### 4. Drug Safety (CTGOV) Page
- Summary metrics: 40 total adverse events, 10 drugs covered, 10 clinical trials
- Filterable adverse effects table by drug and severity
- **Patient Medication Safety Checker** — Select any patient, see all CTGOV-reported adverse events for their active medications with warning banners for serious events

### 5. Copilot Chat (Q&A with Citations)
- Free-text natural language Q&A powered by the Cortex Agent
- Sample question chips for common clinical queries
- Patient scope filter to focus questions on a specific patient
- Every answer includes cited source evidence with expandable excerpts
- Cached responses — the agent is not re-called on page rerun

**Key design decisions:**
- **100% Snowflake-native** — No external APIs, no separate vector database, no external LLM calls
- **Cortex Agent as orchestrator** — Routes quantitative questions to Analyst (SQL) and evidence questions to Search (documents), or both
- **Cited answers only** — Every response includes source document titles and relevant excerpts. No opaque predictions.
- **CTGOV linked to medications** — Adverse effects joined to patient drug lists by drug name

## Data

All data is **fully synthetic** — no real PHI.

### Structured Tables (3,238 records)

| Table | Records | Description |
|-------|---------|-------------|
| PATIENTS | 50 | Demographics, insurance, primary care physician |
| ENCOUNTERS | 500 | Visit type, department, chief complaint, disposition |
| DIAGNOSES | 800 | ICD-10 codes, categories, chronic flag |
| MEDICATIONS | 348 | Drug name, class, dosage, active status |
| LAB_RESULTS | 1,000 | Test name, value, reference range, abnormal flag |
| CLAIMS | 500 | Billed/paid amounts, CPT codes, claim status |
| RISK_SCORES | 50 | HCC score, readmission/fall/med-adherence risk, risk tier |
| CTGOV_ADVERSE_EFFECTS | 40 | Trial-reported adverse events for 10 drugs |

### Unstructured Documents (228 documents, 1,296 search chunks)

| Type | Count | Examples |
|------|-------|---------|
| Clinical Notes | 120 | Physician visit notes with HPI, vitals, exam, assessment/plan |
| Discharge Summaries | 40 | Hospital course, discharge meds, follow-up |
| Radiology Reports | 50 | CT/MRI/X-ray/Echo findings and impressions |
| Regulatory/Safety | 8 | FDA alerts, clinical guidelines, formulary policies |
| CTGOV Trial Reports | 10 | Per-drug adverse event summaries from clinical trials |

## Getting Started

1. Connect to Snowflake account with the HEALTHCARE_COPILOT database
2. Open the Streamlit app: `HEALTHCARE_COPILOT.CORE.PATIENT_360_APP`
3. Explore patients from the Patient List page
4. Click any patient to view their full 360 dashboard with AI summary
5. Use the Copilot Chat to ask natural language questions with cited answers
6. Check the Drug Safety page for CTGOV adverse effect analysis
